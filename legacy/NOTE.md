# Legacy Python scripts (RekordJog 1.x)

These are the original terminal scripts for the Allen & Heath Xone:4D, Hercules DJControl
and Numark Mixtrack 3. They are kept for reference only and are **not** used by RekordJog 2.

They required replacing rekordbox's built-in `PIONEER DDJ-SX.midi.csv` with the stripped-down
file in `pioneer_mappings/`. RekordJog 2 needs the **original** rekordbox file, and its system
check will warn you if the old file is still installed. Reinstall rekordbox to restore it.
